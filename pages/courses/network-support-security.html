Network Support and Security

FREE · SELF-PACEDNetworkingIntermediate
COURSE OVERVIEW

What you'll explore

An introduction to the support practices and security considerations involved in maintaining network environments.

  • Network support fundamentals
  • Common operational support concepts
  • Foundational network security awareness

Learning outcomes

By the end of this course, learners should be able to:

  • Apply effective troubleshooting methodologies and help-desk best practices.
  • Explain common endpoint threats, vulnerabilities and attacks.
  • Describe essential configuration steps for secure user access on a network.

Who is this course for?

Learners interested in network operations, technical support and security fundamentals.
