COURSE OVERVIEW

What you'll explore

An introduction to the concepts and practices used to protect network environments from security threats.

  • Network defense concepts
  • Security threats and protection principles
  • Defensive thinking for network environments

Learning outcomes

By the end of this course, learners should be able to:

  • Explain defense-in-depth and core network-defense principles.
  • Apply access-control concepts and understand access control lists.
  • Describe firewall technologies, cloud security and cryptography.
  • Understand security data sources and how security alerts are evaluated.

Who is this course for?

Learners interested in cybersecurity and protecting network infrastructure.
